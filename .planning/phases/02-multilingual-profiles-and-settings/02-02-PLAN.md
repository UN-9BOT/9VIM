<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| SAF URI/provider grant → application | Provider identity, bytes, and persisted grant state are untrusted platform inputs. |
| UI/archive inputs → LanguageManager | Strict input validation must reject malformed records and invariant-breaking transitions. |
| ZIP archive → staging filesystem | Plan 04 must contain paths and enforce entry/per-entry/aggregate quotas. |
| Staging → durable snapshot/files | Plan 04 must validate and stage fully before one replacement commit. |
| Durable state → exported archive | Plan 04 must exclude typed text and NLP/learning data by explicit whitelist. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-04 | Information disclosure / DoS | CustomLayoutImportAdapter | high | mitigate | Read-only grant only; release newly acquired grant on rejection; no broad storage/network permission. |
| T-02-05 | Tampering / DoS | LanguageManager transitions | high | mitigate | Pure operation-specific normalization, one aggregate commit, final-enabled rejection, and full fallback matrix tests. |
| T-02-06 | Tampering | Custom identity/cache cleanup | medium | mitigate | Canonical URI dedupe, immutable profile IDs, explicit cleanup ownership, and no provider delete/write calls. |
| T-02-02-ZIP | Tampering / DoS | Archive extraction | high | mitigate | Plan 04 enforces canonical containment, duplicate-path rejection, and count/per-entry/aggregate byte quotas before manager input. |
| T-02-02-RESTORE | Tampering | Restore transaction | high | mitigate | Plan 04 stages, parses, validates, copies and maps before one `replaceAll` commit; manager rejects invalid aggregate input. |
| T-02-02-PRIVACY | Information disclosure | Backup export | high | mitigate | Plan 04 allowlists only LanguageConfig and referenced custom documents and asserts typed/NLP data absence. |
</threat_model>
