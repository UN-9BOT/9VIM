<threat_model>
Security acceptance policy: **OWASP ASVS Level 1; block on high-severity threats.** Any unresolved high-severity item blocks plan completion.

## Trust Boundaries

| Boundary | Description |
|---|---|
| SharedPreferences/archive input → domain | Local or restored bytes may be stale, malformed, duplicated, or from a newer schema and require strict input validation. |
| SAF URI/provider grant → application | Custom content and persisted read grants are untrusted and must stay read-only and balanced. |
| ZIP archive → staging filesystem | Later restore must enforce path containment and entry/byte quotas before materialization. |
| Staging → durable snapshot/files | Later restore must validate/copy/map fully and commit the aggregate last. |
| Durable state → exported archive | Later export must exclude typed text and NLP/learning data by whitelist. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Tampering / DoS | LanguageConfigSerDe | high | mitigate | Version/type validation, duplicate rejection, deterministic safe repair, and tests distinguishing absent from malformed-present data. |
| T-02-02 | Tampering | LanguageMigration | high | mitigate | Aggregate-presence idempotence guard, validated custom inputs, deterministic ordering, and D-14 fallback tests. |
| T-02-03 | DoS | LanguageManager → Vim8ImeService | high | mitigate | Load and validate before the sole write; publish one non-null resolved session only after success. |
| T-02-01-SAF | Information disclosure / DoS | SAF grants and custom inputs | high | mitigate | Plan 02 enforces read-only grant acquisition/release and manager validation; this plan exposes no bypass around that boundary. |
| T-02-01-ZIP | Tampering / DoS | Archive extraction | high | mitigate | Plan 04 requires canonical containment plus entry/per-entry/aggregate quotas before any restore input reaches LanguageMigration or LanguageManager. |
| T-02-01-RESTORE | Tampering | Restore transaction | high | mitigate | Plan 04 stages and validates all inputs, remaps IDs, then invokes exactly one manager replacement commit last. |
| T-02-01-PRIVACY | Information disclosure | Backup export | high | mitigate | Plan 04 uses an allowlist limited to LanguageConfig and referenced layout documents and asserts typed/NLP data absence. |
