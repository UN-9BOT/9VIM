<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Android ContentProvider → layout loader | Provider data, availability, and permission are untrusted. |
| YAML bytes → persisted active/history state | Malformed input must not mutate durable preferences. |
| Content cache → URI registry | Shared bytes must not collapse user-visible identities. |

## STRIDE Threat Register — ASVS Level 1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-PROVIDER | Denial of service | Layout.loadKeyboardData | high | mitigate | Convert null/throw/revoked permission to typed failure, close streams, prune persisted stale URI. |
| T-02-INPUT | Tampering | AvailableLayouts import | high | mitigate | Parse/schema/zero-layer validation completes before current/history mutation. |
| T-02-DUP | Tampering | URI history | medium | mitigate | URI-keyed upsert and deterministic de-duplication; tests cover repeated import. |
| T-02-HASH | Spoofing | MD5 cache | high | mitigate | MD5 never identifies a layout or proves integrity; two same-MD5 URIs stay separate. |
| T-02-RACE | Tampering | resolver read/cache | high | mitigate | Digest and parse a single closed byte snapshot and test changed-content refresh/failure transactionality. |
</threat_model>
